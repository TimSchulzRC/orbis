# Orbit logo

The open O represents a place for collected notes and projects. The separate tile represents the next object to add or connect.

`obtion-logo.svg` is the editable light master. `obtion-logo-dark.svg` is its dark variant. The in-app mark and favicon follow the app theme. PWA icons and the Apple touch icon use the light version.

Run `bun scripts/generate-icons.ts` to regenerate the public assets. This requires the Playwright Chromium installation also used by the browser smoke tests.
