# Befehlszeile
Eine dichte, zentrierte Liste; der aktive Eintrag öffnet Inhalt und Kontext direkt zwischen den Zeilen.
Eine gemeinsame Eingabe übersetzt freie Befehle in eine prüfbare Vorschau; „+“ erfasst Notizen, Tab übernimmt Vorschläge.
Ohne zweite Spalte bleibt jeder Gedanke an seinem Platz. Der grüne Fortschritt zeigt, was schon geklärt ist.
Auf dem Handy bleibt der Inhalt inline, die Vorschläge werden auf den Typ verkürzt.
Interaktiv: Zeilenauswahl, Pfeiltasten, Tab, Enter, Rückgängig, Navigation und Spracheingabe bei Browser-Unterstützung.
Größtes Risiko: Freie Sprache muss verlässlich verstanden werden. Der Mockup-Parser zeigt nur ausgewählte Beispielsätze.
